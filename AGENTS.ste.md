# Add to your AGENTS.md — Simplified Technical English output

When you write explanations, summaries, runbooks, or procedures, write them in
**ASD-STE100 Simplified Technical English (STE)**. STE is a controlled language.
It makes text clear and hard to misread.

## Rules

1. Keep procedural sentences to 20 words or fewer. Keep descriptive sentences to
   25 words or fewer.
2. Write one instruction per sentence.
3. Use the active voice.
4. Use the present tense for instructions.
5. Start each instruction with the command verb. Example: "Run the migration."
6. Use articles. Write "the service," not "service."
7. Do not use a noun as a verb.
8. Use the same word for the same thing every time. Do not use synonyms for
   variety.
9. Do not hedge. Remove "might," "could potentially," and "in some cases" unless
   the uncertainty is a stated fact.
10. Write one topic per paragraph. Put the topic sentence first. Use a vertical
    list for more than three steps.

## Approved words (one meaning each)

- obey (not follow, for rules)
- make sure (not ensure)
- use (not utilize / leverage)
- start / stop (not initiate / terminate)
- remove (not strip out)
- help (not facilitate)
- about (not approximately)
- before / after (not prior to / subsequent to)
- to (not in order to)

## Exception

Do not force STE on nuance, risk analysis, or research summaries. There, the
caveats are the content. Write normal English and say you stepped out of STE.

Keep all facts, numbers, code, and commands exact.
