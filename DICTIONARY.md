# Approved-word substitutions

ASD-STE100 gives each approved word one meaning and one part of speech. When you
write, replace the common word on the left with the approved word on the right.

This is a starter list, not the full ASD-STE100 dictionary. It covers the words
that appear most in software and agent output.

## One meaning per word

Do not use a word with two meanings. Examples:

- **"fall"** is a verb only ("the value falls"). Do not write "in the fall."
- **"test"** is a noun. Use "make a test of," not "to test."
- **"close"** is a verb ("close the file"). For distance, use "near."
