# ASD-STE100 Simplified Technical English — Writing Rules (condensed)

This is an original, condensed restatement of the publicly described structure
of ASD-STE100. It is not the Specification text.

## Sentences

- **R1.** Procedural sentence: 20 words maximum.
- **R2.** Descriptive sentence: 25 words maximum.
- **R3.** One instruction per sentence. Split compound instructions.
- **R4.** One main idea per sentence.

## Grammar

- **R5.** Use the active voice. "Remove the panel," not "the panel must be removed."
- **R6.** Use the present tense for instructions and descriptions of fact.
- **R7.** Start an instruction with the command verb.
- **R8.** Use articles ("the," "a") in every noun phrase.
- **R9.** Do not use a noun as a verb. "Make a test of," not "test out."
- **R10.** Do not use a gerund where a plain verb works.
- **R11.** Use the same word for the same thing every time. Do not use synonyms
  for variety.

## Vocabulary

- **R12.** Use only approved words. Each approved word has one meaning and one
  part of speech. See DICTIONARY.md.
- **R13.** If a word is not approved, rewrite the sentence around an approved word.
- **R14.** Keep technical names and technical verbs from your domain. Define them
  once.

## Structure

- **R15.** One topic per paragraph. Put the topic sentence first.
- **R16.** A procedural paragraph: 6 sentences maximum.
- **R17.** Use a vertical list for more than three steps, parts, or conditions.
- **R18.** Put a warning or caution before the step it applies to, never after.

## Tone

- **R19.** Do not hedge. State the fact or state the real uncertainty. Remove
  filler like "basically," "essentially," and "in order to."
- **R20.** Write to the reader. Use "you" for the person who does the task.
