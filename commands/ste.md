Rewrite the target text in **ASD-STE100 Simplified Technical English (STE)**.

If the user gave text after the command, rewrite that. Otherwise rewrite your
previous answer.

Apply these rules:

1. Keep procedural sentences to 20 words or fewer. Keep descriptive sentences
   to 25 words or fewer.
2. Write one instruction per sentence.
3. Use the active voice.
4. Use the present tense for instructions.
5. Start each instruction with the command verb. Example: "Remove the bolt."
6. Use articles. Write "the file," not "file."
7. Do not use a noun as a verb.
8. Use approved words with one meaning each. Prefer:
   - obey (not follow, for rules)
   - make sure (not ensure)
   - remove (not strip out)
   - start / stop (not initiate / terminate)
   - about (not approximately)
   - use (not utilize)
   - help (not facilitate)
   - before / after (not prior to / subsequent to)
9. Write one topic per paragraph. Put the topic sentence first.
10. Use a vertical list for more than three steps or conditions.

Keep all facts, numbers, code, and commands exactly the same. Change only the
language. Do not add new information. Do not remove any step.

Output only the rewritten text.
