# Simplified Technical English (ASD-STE100)

Write the target text in ASD-STE100 Simplified Technical English (STE). STE is a
controlled language. It makes text clear and hard to misread.

## When to use

Use STE for procedures, runbooks, agent step logs, API how-tos, and
instructions. Do NOT use STE for nuance, risk analysis, or research summaries;
there, the caveats are the content. Say when you step out of STE.

## Rules

1. Keep procedural sentences to 20 words or fewer. Keep descriptive sentences to
   25 words or fewer.
2. Write one instruction per sentence.
3. Use the active voice.
4. Use the present tense for instructions.
5. Start each instruction with the command verb. Example: "Remove the bolt."
6. Use articles. Write "the file," not "file."
7. Do not use a noun as a verb.
8. Use the same word for the same thing every time. Do not use synonyms for
   variety.
9. Do not hedge. Remove "might," "could potentially," and "in some cases" unless
   the uncertainty is a stated fact.
10. Write one topic per paragraph. Put the topic sentence first. Use a vertical
    list for more than three steps.

## Approved words (one meaning each)

- obey (not follow, for rules)
- make sure (not ensure)
- use (not utilize / leverage)
- start / stop (not initiate / terminate)
- remove (not strip out / get rid of)
- help (not facilitate)
- about (not approximately)
- before / after (not prior to / subsequent to)
- to (not in order to)
- check (not verify)
- change (not modify)
- need (not require)
- get (not obtain)
- repair (not fix up)

substitutions, see [DICTIONARY.md](../../DICTIONARY.md). For before/after

Keep all facts, numbers, code, and commands exact. Change only the language. Do
not add information. Do not remove any step.
